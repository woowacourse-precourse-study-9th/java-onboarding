# 기능 구현 목록

# 1번문제

## 초기값 검증
- [ ] 페이지 범위가 1~400이 아니라면 예외
- [ ] 왼쪽이 홀수, 오른쪽이 짝수가 아니라면 예외
- [ ] 오른쪽 값이 왼쪽+1가 아니라면 예외
- [ ] 시작 페이지이거나 마지막 페이지라면 예외

- [ ] 페이지번호의 각 자리 숫자를 나눈다.
- [ ] 나눠진 숫자를 더하거나 곱한 값 중 큰 값을 구한다.
- [ ] 왼쪽, 오른쪽 페이지 중 큰 값을 점수로 반환한다.
- [ ] 포비가 이기면 1, 크롱이 이기면 2, 무승부는 0을 반환한다.
- [ ] 예외면 -1을 반환한다
